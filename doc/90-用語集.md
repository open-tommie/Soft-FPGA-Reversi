# 用語集

## RTL (Register Transfer Level)

**レジスタ転送レベル** — ハードウェア設計の抽象度の一段階。  
クロックごとにレジスタ間でデータがどう転送されるかを記述するレベル。

| 抽象度 | レベル | 記述手段 |
| ------ | ------ | ------- |
| 高 | システムレベル | 「何をするか」 |
| ↕ | **RTL** | クロック単位のレジスタ間データフロー ← Verilog/VHDL |
| ↕ | ゲートレベル | AND/OR/FF の接続 |
| 低 | トランジスタレベル | 物理的実現 |

本プロジェクトでは `rtl/` 配下の Verilog が RTL 記述にあたり、
Verilator が RTL → C++ に変換する。

---

## Verilator

オープンソースの **Verilog → C++/SystemC トランスパイラ**。  
RTL シミュレーションをネイティブ C++ コードに変換することで、商用シミュレータに匹敵する高速シミュレーションを実現する。

- ライセンス: LGPL
- 用途: 機能検証、コシミュレーション（cocotb など）、ソフト FPGA
- 制限: イベント駆動シミュレータではないため、アナログ・タイミング解析には不向き

本プロジェクトでは Verilog で書いた Othello アクセラレータを Verilator で C++ 化し、
Pico SDK ファームウェアから呼び出す構成をとる。
