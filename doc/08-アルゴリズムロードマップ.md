## Step 3 — `pick_corner.v` (角優先) 詳細計画

### 戦略

Othello で最高価値の升は 4 隅（a1/h1/a8/h8）。一度取ると永久に安定石。
角が取れるなら最優先し、取れなければ `pick_lsb` にフォールバックする。

将来サブステップとして **X升回避**（b2/g2/b7/g7 — 相手に角を渡す悪手）も検討。

### ビットボード上の位置

```text
a1=bit0  h1=bit7  a8=bit56  h8=bit63
CORNER_MASK = 64'h8100_0000_0000_0081
```

### モジュール設計 (`rtl/pick_corner.v`)

```verilog
module pick_corner (
    input  wire [63:0] legal_bb,
    output wire [63:0] one_hot,   // 選んだ手 (1-hot)
    output wire [5:0]  index,     // 座標インデックス
    output wire        valid      // 合法手あり
);
    localparam [63:0] CORNER_MASK = 64'h8100_0000_0000_0081;
    wire [63:0] corner_moves = legal_bb & CORNER_MASK;
    wire [63:0] candidates   = corner_moves ? corner_moves : legal_bb;
    // candidates から pick_lsb で 1 手選ぶ
    pick_lsb u_lsb (.in_bits(candidates), .one_hot(one_hot),
                    .index(index), .valid(valid));
endmodule
```

`pick_lsb` を内部でインスタンス化し、角がある場合だけ入力を絞る。

### テスト方針

`verif/tb_unit/pick_corner/test_pick_corner.py`

| テストケース | 確認内容 |
| --- | --- |
| 角が 1 つ合法手にある | その角が選ばれる |
| 角が複数合法手にある | 行優先で最初の角が選ばれる |
| 角が合法手にない | `pick_lsb` と同じ手が選ばれる |
| 合法手なし | `valid=0` |
